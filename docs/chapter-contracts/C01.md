# C01 contract — The Count Is Not the Cost

## Opening phenomenon

A zero-FLOP copy and a fused affine transform have nearly identical compulsory
traffic, while a much larger matrix-product count can exploit reuse. Operation
count does not identify the limiting resource.

## Diagnostic chain

Symptom → FLOP ranking disagrees with resource opportunity. Instrumentation →
declare $F$, $Q$, traffic boundary, $P_{\max}$, and $B$. Theory →
$P\leq\min(P_{\max},BI)$. Cure → classify transformations by the constrained
resource and retain a hardware-claim boundary.
