# C16 contract — The Boundary Moves

## Opening phenomenon

A laptop-reproducible two-parameter full-batch trajectory begins below
$2/\alpha$, later crosses it, and develops bounded nonmonotone loss.

## Diagnostic chain

Prove the fixed quadratic control; track top and gradient-direction curvature;
compare them with loss increments and finite-horizon history; route the
large-model phenomenon to primary evidence.

## Evidence and theorem

- `c16-moving-boundary-001`, class (a); scale extensions alone may be class (c).
- `thm-c16-quadratic-stability`, full proof.
- Harness `ch-16`, API 0.16.

## Boundaries

Crossing $2/\alpha$ is not called universal divergence outside a fixed
quadratic. Flat-minimum/generalization claims stay off-arc. Staircase variants
are named as paper-audit branches, not silently imported.

## Handoff

C17 moves from scalar step stability to the norm geometry of matrix updates.
